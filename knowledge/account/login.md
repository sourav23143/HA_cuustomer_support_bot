# Login Issues — Troubleshooting Guide

*This document is fictional and for demo purposes only.*

## Common Login Problems

### Cannot Log In

1. Ensure you are using the correct phone number or email registered with HealthAssist.
2. Check for typos in your credentials.
3. If using social login (Google, Apple), ensure the correct account is selected.
4. Try clearing your browser cache or app data.

### Account Locked

If you see an "Account Locked" message:
- Your account may have been temporarily locked due to multiple failed login attempts.
- Wait 30 minutes and try again.
- If the issue persists, contact support.

### Password Reset

1. Click "Forgot Password" on the login screen.
2. Enter your registered email address.
3. Check your email for a password reset link (check spam/junk folder).
4. Create a new password and log in.

### Browser Compatibility

HealthAssist supports:
- Google Chrome (latest version)
- Mozilla Firefox (latest version)
- Apple Safari (latest version)
- Microsoft Edge (latest version)

If you are using an unsupported browser, please switch to one of the above.
